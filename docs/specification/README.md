# Lemon language specification

**Status:** pre-draft. This directory records language decisions before implementation.

Planned documents:

1. `lexical-grammar.md`: source encoding, identifiers, keywords, literals and comments.
2. `syntactic-grammar.ebnf`: first review draft covering the hello examples, with the wider grammar still open.
3. `type-system.md`: explicit types, records, classes, generics and polymorphism.
4. `ownership.md`: `view`, `edit`, `store`, moves, borrows and lifetimes.
5. `concurrency.md`: threads, tasks, actors and processes.

These are specifications, not claims of implementation.
